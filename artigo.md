# VISUAL STUDIO CODE E GITHUB: INTEGRAÇÃO DE FERRAMENTAS NO DESENVOLVIMENTO DE SOFTWARE

**Rafael Capistrano**

## Resumo

O desenvolvimento de software envolve a utilização de diferentes ferramentas para criação, organização e manutenção de projetos. Entre essas ferramentas, destacam-se o Visual Studio Code, utilizado como ambiente de desenvolvimento, e o GitHub, plataforma voltada ao armazenamento, versionamento e colaboração em projetos. Este artigo apresenta uma breve análise dessas ferramentas e de sua integração, destacando como a utilização conjunta pode facilitar o desenvolvimento de software, o controle das alterações realizadas e o trabalho colaborativo. Também são abordadas algumas possibilidades de utilização dessas tecnologias no contexto acadêmico e profissional.

**Palavras-chave:** Visual Studio Code. GitHub. Git. Controle de versões. Desenvolvimento de software.

## 1 INTRODUÇÃO

O desenvolvimento de software moderno depende de ferramentas que permitam não apenas escrever código, mas também organizar projetos, acompanhar alterações e possibilitar a colaboração entre diferentes desenvolvedores. Nesse contexto, os sistemas de controle de versões tornaram-se importantes para o gerenciamento do código-fonte e para a manutenção do histórico de um projeto.

Segundo Konnorate et al. (2019), o controle de versões é um recurso importante no desenvolvimento de software, especialmente em projetos nos quais diferentes pessoas trabalham simultaneamente. Entre as tecnologias utilizadas para essa finalidade estão o Git e o GitHub, que permitem acompanhar alterações e organizar diferentes versões dos arquivos de um projeto.

Paralelamente, ambientes de desenvolvimento como o Visual Studio Code oferecem recursos que facilitam a criação e edição dos arquivos utilizados nos projetos. A integração entre um ambiente de desenvolvimento e uma plataforma de versionamento proporciona um fluxo de trabalho mais organizado e próximo daquele utilizado profissionalmente.

## 2 VISUAL STUDIO CODE

O Visual Studio Code é um editor de código-fonte desenvolvido pela Microsoft que possui suporte a diversas linguagens de programação e extensões. Além da edição dos arquivos, a ferramenta disponibiliza recursos que auxiliam o desenvolvedor durante o processo de programação, como terminal integrado, extensões e ferramentas de controle de versão.

Um dos recursos importantes para o desenvolvimento de software é a integração com o Git. Por meio do próprio ambiente do Visual Studio Code, o desenvolvedor pode visualizar alterações realizadas nos arquivos, preparar modificações para um *commit*, consultar o histórico e sincronizar o projeto com um repositório remoto.

Essa integração reduz a necessidade de alternar constantemente entre diferentes programas, permitindo que grande parte das atividades relacionadas ao desenvolvimento e ao versionamento seja realizada dentro do mesmo ambiente.

## 3 GIT E GITHUB

O Git é um sistema distribuído de controle de versões utilizado para registrar alterações realizadas em arquivos de um projeto. Por meio dele, é possível criar *commits*, consultar o histórico de modificações e trabalhar com diferentes *branches*, permitindo o desenvolvimento de funcionalidades de maneira organizada.

O GitHub, por sua vez, disponibiliza uma plataforma para hospedagem de repositórios Git e oferece recursos voltados à colaboração. Dessa forma, os arquivos de um projeto podem ser armazenados remotamente e compartilhados com outras pessoas.

Konnorate et al. (2019) destacam a importância do Git e do GitHub no controle de versões e no desenvolvimento colaborativo de software. O uso dessas ferramentas permite manter um histórico das alterações realizadas, facilitando a identificação e o gerenciamento das diferentes versões de um projeto.

Além do desenvolvimento profissional, o GitHub também pode ser utilizado no ambiente acadêmico. Presto e Neiva (2018) apresentam uma proposta de utilização do GitHub como ferramenta de colaboração e aprendizagem, explorando recursos como repositórios, *issues*, *pull requests* e controle de versões.

## 4 INTEGRAÇÃO ENTRE VISUAL STUDIO CODE E GITHUB

A integração entre Visual Studio Code, Git e GitHub permite estabelecer um fluxo de trabalho relativamente simples. Inicialmente, um projeto pode ser criado ou clonado para o computador do desenvolvedor. Os arquivos são então editados utilizando o Visual Studio Code.

Após a realização das modificações, o Git identifica quais arquivos foram alterados. Essas alterações podem ser registradas por meio de um *commit*, criando um ponto no histórico do projeto. Posteriormente, os *commits* podem ser enviados para o repositório remoto no GitHub por meio de um *push*.

Também é possível obter alterações realizadas no repositório remoto utilizando o *pull*. Dessa forma, o desenvolvedor consegue manter sua cópia local atualizada com o projeto armazenado no GitHub.

Sá (2023), em seu Trabalho de Conclusão de Curso desenvolvido na Universidade Federal de Santa Catarina, apresenta uma proposta de ensino do GitHub para estudantes de tecnologia, incluindo a utilização de repositórios e ferramentas relacionadas ao desenvolvimento de software.

Assim, o aprendizado dessas ferramentas durante a graduação pode proporcionar ao estudante uma experiência mais próxima das práticas utilizadas no desenvolvimento profissional.

## 5 IMPORTÂNCIA PARA O DESENVOLVIMENTO DE SOFTWARE

A utilização conjunta dessas ferramentas apresenta benefícios tanto para projetos individuais quanto para trabalhos realizados em equipe. O controle de versões permite acompanhar o histórico do projeto e identificar alterações realizadas ao longo do desenvolvimento.

Em projetos colaborativos, recursos como *branches* e *pull requests* possibilitam que diferentes desenvolvedores trabalhem em funcionalidades distintas e posteriormente integrem suas alterações. Além disso, o GitHub permite compartilhar projetos e facilitar a comunicação entre os participantes.

No ambiente acadêmico, essas ferramentas também podem contribuir para o desenvolvimento de habilidades práticas. O estudante pode utilizar o GitHub para armazenar trabalhos, documentar sua evolução e desenvolver projetos de maneira organizada. Dessa forma, além de aprender programação, passa a conhecer ferramentas utilizadas no cotidiano profissional da área de tecnologia.

## 6 CONCLUSÃO

O Visual Studio Code, o Git e o GitHub são ferramentas que podem atuar de maneira integrada durante o desenvolvimento de software. Enquanto o Visual Studio Code fornece recursos para criação e edição dos projetos, o Git permite controlar suas versões e o GitHub possibilita armazenar e compartilhar os repositórios remotamente.

A integração dessas ferramentas proporciona um fluxo de trabalho mais organizado, facilita o acompanhamento das alterações e possibilita a colaboração entre diferentes pessoas. Além disso, sua utilização no ambiente acadêmico pode contribuir para aproximar os estudantes das práticas encontradas no mercado de trabalho.

Portanto, conhecer essas ferramentas representa uma competência relevante para estudantes e profissionais de tecnologia, principalmente em projetos que envolvem desenvolvimento colaborativo e necessidade de controle sobre as diferentes versões do software.
